## Selected work

### 01 — [AkiMatch](https://akimatch.beni-works.workers.dev/)

> 大学生の「空いている時間」を重ねる。

授業やアルバイトで予定がばらばらな学生グループ向けの日程調整アプリ。認証なしの共有URL、24時間のヒートマップ、上位3候補によって、全員が集まりやすい時間を可視化します。

`Next.js` `TypeScript` `Drizzle ORM` `Cloudflare Workers` `D1`

### 02 — [たびぽん](https://github.com/monarizzz/tabipon) · [Story](https://topaz.dev/projects/8af82f7dea8d61828a3e)

> 旅の写真を、自分だけのスタンプに。

撮った写真を加工し、位置情報と一緒に旅のスタンプとして残すモバイルアプリ。画像処理API、位置情報、データベース連携、スタンプを押すUIを担当しました。チームハッカソンで最優秀賞を受賞。

`Expo` `React Native` `FastAPI` `OpenCV` `Supabase`

### 03 — [ユル単](https://github.com/hamabira/hackstage_stage2_rakutanzenya)

> あと何回休めるか、あと何点必要か。

科目ごとの出席条件と評価割合をまとめ、残りの欠席可能回数や目標成績に必要な点数を計算するWebアプリ。感覚で管理しがちな履修状況を、次に取るべき行動へ変換します。

`Next.js` `TypeScript` `Supabase` `Cloudflare Workers`
