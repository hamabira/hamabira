## 🧭 Selected work

### [![01 AkiMatch](https://img.shields.io/badge/01-AkiMatch-2563EB?style=for-the-badge&amp;labelColor=1F2937)](https://akimatch.beni-works.workers.dev/)

> 大学生の「空いている時間」を重ねる。

授業やアルバイトで予定がばらばらな学生グループ向けの日程調整アプリ。認証なしの共有URL、24時間のヒートマップ、上位3候補によって、全員が集まりやすい時間を可視化します。

`Next.js` `TypeScript` `Drizzle ORM` `Cloudflare Workers` `D1`

### [![02 たびぽん](https://img.shields.io/badge/02-%E3%81%9F%E3%81%B3%E3%81%BD%E3%82%93-B45309?style=for-the-badge&amp;labelColor=1F2937)](https://github.com/monarizzz/tabipon) · [Story](https://topaz.dev/projects/8af82f7dea8d61828a3e)

> 旅の写真を、自分だけのスタンプに。

撮った写真を加工し、位置情報と一緒に旅のスタンプとして残すモバイルアプリ。画像処理API、位置情報、データベース連携、スタンプを押すUIを担当しました。チームハッカソンで最優秀賞を受賞。

`Expo` `React Native` `FastAPI` `OpenCV` `Supabase`
